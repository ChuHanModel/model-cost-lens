# Model Cost Lens · 模型成本透镜

输入「缓存输入 : 普通输入 : 输出」的 Token 比例或数量，按 AIHOT 各领域评分与三项单价计算模型成本和性价比边界。

[在线工具](https://model-cost-lens.linyi-wang.chatgpt.site) · [数据来源](https://aihot.news/leaderboard)

## 使用

1. 输入三项相对用量，自动归一化；缓存输入和普通输入互不重复。
2. 选择综合、编程、科研、专业办公或知识问答，可叠加国产与已核验开源权重筛选。
3. 表格按折算价排序，图中绿色表示没有成本不高且评分不低的更优替代。搜索只过滤表格，不改变斩杀线。

折算价 = (缓存单价 × 缓存输入 + 普通输入单价 × 普通输入 + 输出单价 × 输出) / 三项用量之和，单位为人民币 / 百万总 Token。

## 统一快照

`dist/snapshot.json`：2026-10-06 抓取五个分类 × 四种筛选组合的所有可见表格行；再遍历 90 个公开评测来源页，核对 65 个型号详情。57 个型号已入榜，8 个尚未入榜。各分类评分与原榜名次分别保存；保留价格未知值、官方报价和权重链接、来源 URL、抓取时间和组合覆盖记录。

原站各页面最多展示 30 个型号。快照覆盖所遍历页面公开展示的型号，**未证明覆盖 AIHOT 后台全部型号**。这是静态快照，不是实时行情。没有重新核验每家厂商单价；尚未入榜型号的已有评分仅供查看，不参与斩杀线。未核实的开源标记保持未知。

零占比部分无需单价，其余部分未知则不估价。不同模型实际 Token 数、输出长度、推理输出、缓存写入、存储、阶梯价和订阅费差异未计入。评分不是正确率。代码 MIT，数据权益与原始来源保留。与 AIHOT 无官方关系。

## 本地运行

无需依赖安装，Node 22+ 用于检查和测试，Python 3 用于静态预览。

```sh
npm run check
npm test
npm start
```

打开 http://127.0.0.1:8768 。WebMCP 支持 `configure_cost_scenario`，传入 `cached_input`、`uncached_input`、`output`，复用页面校验与状态。
